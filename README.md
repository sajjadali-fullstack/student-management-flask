# Student Management System (Flask)

##  Description
A simple web app built using Flask and SQLite to manage students.

##  Features
- Add Student
- Edit Student
- Delete Student
- View Student List

## 🛠️ Tech Stack
- Flask
- SQLite
- HTML
- CSS
